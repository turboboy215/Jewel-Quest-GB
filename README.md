# Jewel-Quest-GB
Jewel Quest (Game Boy homebrew game)

A very basic Game Boy game created as part of a learning experience which is a port of a computer game that I made as the final project for a computer programming class in PyGame back in December 2017.

The goal of the game is to collect all the jewels and avoid the ghosts. This game features various concepts like multi-sprite objects, collision detection, input, and audio.
